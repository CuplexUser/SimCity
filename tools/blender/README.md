# Blender → WebCity sprite pipeline

Two headless scripts turn Blender models into the game's sprite atlas, plus one
bootstrap that seeds an **editable** master `.blend`:

| Script | Role |
|--------|------|
| `iso_render.py` | Shared core: the 2:1 dimetric ortho camera, the **neutral daylight light rig**, and the PBR/glass materials. Imported by the others — edit lighting/materials here once and every render follows. |
| `build_city_assets.py` | Seeds the **infrastructure + glass-tower** assets as real meshes (one collection per atlas key) into `city_assets.blend`. Re-running it edits the file in place and **preserves hand-made collections** (the civic buildings). After the first run you mostly edit the `.blend`, not the script. |
| `render_isos.py` | Renders every tagged collection in `city_assets.blend` to sprite PNGs + `spriteMap.json` at the exact in-game projection. |
| `import_kenney.py` | Renders the Kenney City-Kit `.glb` zone buildings (`z:*`). |
| `assemble_modular.py` | Assembles Kenney Modular-Buildings pieces into big multi-tile zone lots (`z:*`). |

## The editable asset workflow (`city_assets.blend`)

`city_assets.blend` holds these assets as **real mesh objects you can open and edit
in Blender**:

- **Infrastructure** — `b:1` coal, `b:8` gas, `b:9` nuclear, `b:10` solar,
  `b:11` wind, `b:2` water tower, `b:12` water pump, `b:13` pumping station,
  `infra:pylon`. *(seeded by `build_city_assets.py`)*
- **Glass curtain-wall towers** — `z:2:2:6` slab, `z:2:2:7` setback, `z:2:2:8`
  twin (commercial high), `z:1:2:3` residential point tower. *(seeded by
  `build_city_assets.py`)*
- **Civic services** — `b:3` police, `b:4` fire, `b:5` hospital, `b:6` school,
  `b:7` library (2×2, windows on all faces). **Hand-authored directly in the
  `.blend`** — NOT generated by any script. Edit them freely in Blender.

Each asset is its own **collection**, named with `_` for `:` (`b_1`, `z_2_2_6`,
`infra_pylon`), carrying a custom int property **`["foot"]`** = its N×N tile
plot. Assets are laid out in a spaced row purely so the file is pleasant to edit;
`render_isos.py` re-centers each on its plot at render time, so the layout offset
does not affect output.

`build_city_assets.py` only owns the seeded (infra/glass) keys: re-running it opens
the existing `.blend` and rebuilds just those, leaving every other `["foot"]`-tagged
collection (the civic buildings) untouched — so regenerating infra never wipes your
hand-made civic art.

```bash
# Edit models in Blender (File > Open city_assets.blend), then re-render:
pnpm render:city          # blender -b city_assets.blend -P render_isos.py -- --out tools/assets-src
pnpm build:atlas          # pack PNGs → public/sprites/

# Re-seed the infra/glass assets (edits the .blend in place; preserves the
# hand-made civic collections + any other manual edits to non-seeded assets):
pnpm gen:city:blend
```

To add an asset: in Blender, model it 1 unit = 1 tile, put it in a new collection
named after its key (`_` for `:`), set the collection's `["foot"]` custom property
(Object/Collection Properties → Custom Properties), save, then `pnpm render:city`.
`z:*` keys are rendered in 4 rotations (r0..r3); every other key renders once.

## Camera: 2:1 dimetric (matches `src/rendering/isoCamera.ts`)

The game tile is **64×32 px** → a 2:1 diamond. An **orthographic** camera at
**azimuth 45°**, **elevation `atan(0.5) ≈ 26.565°`** projects a unit cube's top
face to a 2:1 diamond — true SimCity-style dimetric. `iso_render.setup_camera`
sets `rotation_euler = (π/2 − elev, 0, π/4)`; each renderer sizes `ortho_scale`
so **one Blender unit = one tile**.

## Lighting: neutral daylight (`iso_render.setup_lights`)

A **soft, neutral** rig: a near-white SW key sun balanced by a strong near-white
fill (0.5× the key) and a **flat neutral sky** for even ambient, viewed through
AgX **Base** contrast. Both camera-facing faces read at a similar brightness with
gentle directional form — no blown-out gradient on the sun-facing side. (The old
rig used a hot warm key + a Nishita sky the glass reflected as bright highlights +
AgX high contrast, which washed the glass towers out on one side.) Change the rig
in `setup_lights` / the `look` in `setup_scene` and every sprite re-renders to match.

## Modeling conventions

- **1 Blender unit = 1 tile.** Model an `N×M` building inside `x∈[0,N]`,
  `y∈[0,M]`, `z≥0`. `render_isos.py` re-centers by bounding box, so exact origin
  placement inside the `.blend` doesn't matter; the collection's `["foot"]` sets
  the plot size.
- The pixel **anchor** (the plot's north apex, world `(0, foot, 0)`) and per-sprite
  `tilePx` are measured **empirically** from the projection and written to
  `spriteMap.json`, so they stay correct regardless of framing/resolution.
